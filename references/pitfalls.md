# 跨项目通用坑（踩过的才写）

## 环境
- **Playwright 装错目录**：用户说"装了"，实际装在子目录。自己找 package.json 和 config，不信口头。
- **不要下载内置浏览器**：本机有 Chrome/Edge 就用 channel 指向，省下载时间，也避免版本不一致。
- **package.json type:module**：playwright.config.js 要用 ESM（import），否则报错。
- **后端起不来别急**：先 curl 健康检查，看日志，别盲目跑测试。

## 选择器
- **别猜 class 名**。读模板看真实 class。`.option-item` 不存在，实际可能是 `.opt`。
- **后代选择器 vs 连写**：`.res .wrong`（后代）和 `.res.wrong`（同一元素）完全不同，看 DOM 结构。
- **异步渲染**：列表/卡片是接口拉的，先 waitForSelector 再操作，别固定等 3 秒。

## 接口
- **先接口后 UI**：后端 API 是真相源，先打穿业务逻辑再点页面。
- **判成功要看数据**：接口返回 completed 不等于真成功——这次就是题目数组空但 count 写死，假成功。
- **前后端路径要对一遍**：前端 fetch 的路径和后端 Controller 的路径可能对不上（收藏 bug）。

## 数据与状态
- **时间敏感功能**：需要"明天到期"类，问用户能否改测试数据模拟，别真等。
- **测试用户隔离**：每用例新建随机用户名，不串数据。
- **localStorage 脏数据**：造几种坏值（空、坏 JSON、类型错）验证不白屏。
- **快速连续操作**：快速连点切题/按钮，验证不划蓝、不弹复制菜单、不重复提交。

## 执行
- **串行跑**（workers:1），有依赖的用例不并行。
- **trace 全程录**，失败自动留截图和网络请求。
- **只测不改**：发现 bug 记录，不自己修。
